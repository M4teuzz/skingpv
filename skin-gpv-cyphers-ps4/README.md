# Cyphers PS4 / DualShock 4

Overlay Oni/Cyphers adaptado ao arranjo simetrico dos controles PlayStation 4 / DualShock 4.

## Layout

- Analogicos esquerdo e direito alinhados na mesma altura.
- L2 e R2 representados pelos pedais laterais.
- Tamanho recomendado da fonte de navegador: **560 x 300 px**.

Cada analogico responde independentemente aos eixos `stick-1` e `stick-2`. A inclinacao 3D e bloqueada no CSS; ainda assim, use `nocurve=1` no link do Gamepad Viewer.

As medidas podem ser refinadas no bloco `:root` de `stylesheet.css`.
